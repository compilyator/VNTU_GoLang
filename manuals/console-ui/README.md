# Консольне оформлення програм Go

Ці матеріали допомагають виконати необов’язкове поглиблення. Основна лабораторна має спочатку правильно виконувати обчислення, перевірки й обробку помилок. Сам імпорт пакета додаткових балів не дає.

Перевірено за офіційною документацією **16 вересня 2026 року**.

## Спільні правила

- Спочатку реалізуйте обов’язкову логіку звичайними засобами Go.
- Не додавайте штучні `time.Sleep` заради анімації.
- Не покладайте зміст лише на колір: додавайте текстові підписи.
- Перевіряйте роботу у своїй ОС і терміналі.
- Обробляйте помилки бібліотеки.
- Після `go get` виконайте `go mod tidy` і подайте оновлені `go.mod` та `go.sum`.
- У звіті зазначте пакет, версію, мету, ключовий код, фактичний результат і обмеження.
