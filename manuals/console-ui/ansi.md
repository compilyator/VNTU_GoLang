# ANSI-кольори й посилання без бібліотек

ANSI escape sequence — керівна послідовність символів, яку сумісний термінал інтерпретує як зміну стилю.

```go
const (
	reset  = "\033[0m"
	red    = "\033[31m"
	green  = "\033[32m"
	yellow = "\033[33m"
	bold   = "\033[1m"
)

fmt.Println(green + "Аналіз завершено" + reset)
fmt.Println(red + "Помилка введення" + reset)
fmt.Println(bold + yellow + "Попередження" + reset)
```

Завжди додавайте `reset`, інакше стиль може перейти на наступний текст. Перевірте Windows Terminal, PowerShell, Bash або zsh, де запускатиметься програма.

## Клікабельне посилання

Деякі термінали підтримують OSC 8:

```go
url := "https://go.dev"
label := "Документація Go"
fmt.Printf("\033]8;;%s\033\\%s\033]8;;\033\\ (%s)\n", url, label, url)
```

URL виводиться також звичайним текстом, бо клікабельність не гарантована.

## Доказ у звіті

Покажіть звичайний і кольоровий режими, поясніть escape sequence та наведіть результат у фактичному терміналі.
