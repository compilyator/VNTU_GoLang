# Додаткові матеріали курсу з Go

Публічні додаткові матеріали, інструкції та навчальні дані для курсу з програмування мовою Go у Вінницькому національному технічному університеті.

Курс викладається в межах освітньої програми [«Технології адміністрування та штучного інтелекту в кібербезпеці»](https://cybersecurity.vntu.net/) спеціальності **F5 «Кібербезпека та захист інформації»**.

## Лабораторні роботи

- [Матеріали до лабораторних робіт](labs/README.md) — навчальні пакети, приклади, дані та допоміжні інструкції.

## Практичні інструкції

- [Практичні інструкції та огляди інструментів](manuals/README.md) — додаткові матеріали для виконання навчальних завдань.

## Навчальні приклади

- [Невеликі приклади Go](examples/README.md) — модулі, консольне введення, підкоманди, табличні тести, чистий `main` і тестоване виведення.

Матеріали призначені для виконання навчальних завдань. Генератори не моделюють реальні системи й не придатні для створення паролів, токенів або криптографічних ключів.
