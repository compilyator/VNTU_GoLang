## Навчальні файли для лекції 6

Кожну незалежну задачу починайте зі свіжої копії цього набору. Усі дані вигадані. Не переносіть вправи видалення чи зміни дозволів за межі копії. Каталоги `archive`, `output` і `work` створюйте за умовами задач.

## Потоки

У каталозі набору зберіть програму: PowerShell — `go build -buildvcs=false -o stream.exe .`, Bash — `go build -buildvcs=false -o stream .`. Потрібен Go 1.24 або новіший. Програма читає до EOF не більше 100 цілих від -1000 до 1000. Успіх: `COUNT n SUM s` у stdout, `DONE` у stderr, код 0. Помилки у stderr, порожній stdout, код 2. Різні способи перенаправлення наведено в задачнику.

## Git-стенди без зовнішнього сервера

Потрібен встановлений Git із командами `switch` та `init -b`. Для `.ps1` використовуйте PowerShell 7; альтернативою є Bash, зокрема Git Bash на Windows. Відкрийте термінал у каталозі зі сценаріями. Перегляньте сценарій перед запуском. Він створює тільки новий дочірній каталог і налаштовує автора лише всередині створених репозиторіїв. Наявний каталог не перезаписується, глобальні налаштування Git не змінюються, мережа не використовується.

**PowerShell:**

```powershell
.\setup.ps1 -Name git-lab
```

Якщо Windows позначила завантажений сценарій і блокує запуск, спочатку перегляньте його через `cat .\setup.ps1`, потім виконайте `Unblock-File -LiteralPath .\setup.ps1` і повторіть запуск. Якщо діє організаційна заборона сценаріїв, використайте дозволений Bash; не змінюйте політику системи.

**Bash (Linux/macOS або Git Bash для Git-вправ):**

```bash
bash setup.sh git-lab
```

Успіх: `READY git-lab`. У створеному каталозі:

- `basic`: гілка `main` з одним комітом; `value.txt` містить `10`, `notes.txt` — `alpha`. Гілка `feature` додає `feature.txt` із рядком `feature`.
- `conflict`: у `main` файл `message.txt` містить `color=red`; у `update` — `color=green`; спільна початкова версія — `color=blue`.
- `remote.git`: локальний сервер історії, без робочого дерева.
- `alice`, `bob`: дві незалежні робочі копії цього сервера, обидві на `main` із початковим `value.txt = 10`.

Для іншої незалежної задачі запустіть сценарій із новою назвою, наприклад `git-task-42`. У разі перерваної підготовки також оберіть нову назву. Не видаляйте старий каталог автоматично. Дати, хеші комітів і абсолютні шляхи можуть відрізнятися — у задачах перевіряються зміст і зв’язки комітів.
