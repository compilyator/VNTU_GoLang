## Навчальні CLI для підлекції 6А

Потрібен Go 1.24 або новіший. Набір використовує лише стандартну бібліотеку; мережеві залежності не завантажуються. Працюйте у свіжій копії, у корені, де лежать `go.mod`, `cmd`, `data` та `sandbox`.

### Збірка

**PowerShell:**

```powershell
mkdir bin
$names = 'probe', 'sum', 'hello', 'child', 'runner', 'reader', 'starter'
foreach ($name in $names) { go build -buildvcs=false -o "bin/$name.exe" "./cmd/$name"; if ($LASTEXITCODE -ne 0) { throw "Build failed: $name" } }
.\bin\hello.exe
```

**Bash:**

```bash
mkdir bin
for name in probe sum hello child runner reader starter; do
  go build -buildvcs=false -o "bin/$name" "./cmd/$name" || exit 1
done
./bin/hello
```

На Windows запускайте з `bin` файли `.exe`, на Linux/macOS — без розширення. Далі задачник показує обидві форми. Для перевірки власного коду після зміни виконайте `gofmt -w cmd/starter/main.go` та повторно зберіть `starter`. Код завершення перевіряйте у зібраного файла, а не через `go run`: він може повертати код процесу-обгортки.

### Готові програми

- `probe`: показує кількість аргументів без імені програми, потім індекс і Go-подання кожного рядка в лапках. Нічого не виконує з переданого тексту.
- `sum`: приймає 1–100 позиційних цілих від -1000 до 1000, друкує суму. Неправильна кількість — `ARGUMENT ERROR`, перетворення — `FORMAT ERROR`, діапазон — `RANGE ERROR`, код 2.
- `hello`: `-name` (student), `-count` (1, дозволено 1–3), `-upper` (false), `-timeout` (2s, дозволено більше нуля й до 10s), `-verbose` (false). Ім’я 1–20 кодових точок без переносів. Позиційних аргументів немає. Друкує привітання, а в докладному режимі — `TIMEOUT ...` у stderr. Тайм-аут тут тільки параметр демонстрації: очікування або мережевої операції немає.
- `child`: приймає рівно `--` і один текст до 80 байтів, друкує `VALUE` та текст у лапках.
- `runner`: передає один текст до 80 байтів програмі `child`, що лежить поруч із ним. Оболонка та пошук через `PATH` не використовуються.
- `reader`: `-file` — потрібне відносне ім’я, `-max-bytes` — 32 за замовчуванням, дозволено 1–1024. Корінь читання — лише `sandbox/allowed`. Для переносимості дозволено `/`, заборонено `\`, `:`, абсолютні шляхи та сегмент `..`. Обмеження імені — 200 байтів. `os.Root` обмежує фактичне відкриття; читаються лише звичайні файли. Помилка параметрів має код 2, відкриття/читання/завеликий файл — 1. Вміст виводиться без додаткового переносу.
- `starter`: навмисно незавершений, але компільований каркас для ваших розв’язань. До виконання задач він друкує `NOT IMPLEMENTED` у stderr і завершується кодом 2. Це не готовий розв’язок.

Усі названі помилки потрапляють у stderr; до них stdout порожній. Кожна текстова діагностика завершується переносом. Довідка `hello` та `reader` має stdout, порожній stderr і код 0.

### Межі стенду

Усі дані вигадані. `sandbox/private/demo-secret.txt` містить тільки маркер `DEMO_MARKER_NOT_A_SECRET`. Не використовуйте реальні секрети, чужі каталоги, мережеві цілі, Administrator/root. Для командних рядків із `;`, `$` та іншими символами оболонки користуйтеся саме лапками з прикладу. Вправи з посиланнями виконуються тільки всередині цього стенду й є необов’язковими.

Файли `exact.txt` і `over.txt` містять відповідно 32 та 33 ASCII-байти `x` без переносу. `report.txt` містить 11 байтів: `alpha`, LF, `beta`, LF. Архів зберігає LF незалежно від ОС. Не перезберігайте ці файли редактором перед перевіркою межі байтів.
