# Підлекція 8А: набори для пакетів, інкапсуляції та тестів

Файл із задачами отримайте від викладача. Тут лише початкові архіви й інструкції; готових розв’язків немає.

- **S:** [08a-starter.zip](downloads/08a-starter.zip) — готовий Go-модуль із короткою командою та окремим модулем зовнішнього споживача для досліду з `internal`.
- **R:** [08a-regression.zip](downloads/08a-regression.zip) — вісім **навмисно несправних** пакетів для написання регресійних тестів і самостійного пошуку дефектів.
- [Контрольні суми SHA-256](downloads/SHA256SUMS.txt).

## Підготовка

Потрібен Go 1.24 або новіший. Перевірено з Go 1.25.1. Підтримуються Windows із PowerShell та Linux/macOS із Bash. Модулі вже створено, `go mod init` не потрібний. Сторонніх залежностей немає; після завантаження робота локальна.

Завантажте потрібний ZIP і SHA256SUMS.txt до одного каталогу. Звірте контрольну суму **до** розпакування. SHA-256 перевіряє відповідність файлу опублікованій копії. У PowerShell порівняйте Hash з рядком потрібного файла; у Bash команда нижче перевіряє обидва завантажені архіви.

PowerShell:
```powershell
Get-FileHash ./08a-starter.zip -Algorithm SHA256
Get-FileHash ./08a-regression.zip -Algorithm SHA256
cat ./SHA256SUMS.txt
```

Bash (Linux):
```bash
sha256sum -c SHA256SUMS.txt
```

Bash (macOS):
```bash
shasum -a 256 -c SHA256SUMS.txt
```

Для однієї задачі оберіть новий, ще не наявний каталог, наприклад `task-001`. Наступні команди розпаковують S; для R замініть назву ZIP і внутрішнього каталогу на `08a-regression`.

PowerShell:
```powershell
Expand-Archive -LiteralPath ./08a-starter.zip -DestinationPath ./task-001
cd ./task-001/08a-starter
go run ./cmd/demo
```

Bash:
```bash
mkdir task-001
unzip 08a-starter.zip -d task-001
cd task-001/08a-starter
go run ./cmd/demo
```

Початкове виведення S:
```text
10
```

Код завершення — 0. У R команди `cmd/demo` немає: працюйте з пакетом, указаним у задачі. Прочитайте README всередині вибраного набору. Для незалежної задачі беріть свіжу копію.

## Тести та межі досліду

PowerShell:
```powershell
go fmt ./...
go test ./... -count=1
go vet ./...
```

Bash:
```bash
go fmt ./...
go test ./... -count=1
go vet ./...
```

Спочатку тестів у наборах немає. `[no test files]` або `[no tests to run]` не підтверджують контракт. У R спершу напишіть тест за умовою задачі, переконайтеся в його відмові на початковому коді, знайдіть дефект і повторіть перевірку після виправлення. Не змінюйте очікування під несправну реалізацію. Використовуйте лише вигадані дані й маркери токенів.

`outsider` у S має власний `go.mod` із локальним `replace`; кореневий `go test ./...` його не обходить. Запускайте його окремо з каталогу `outsider`, як описано в README набору. Зберігайте вкладену структуру. Навмисно некомпільовані досліди після перевірки відокремлюйте від робочої збірки як `.go.txt`.

Якщо імпорт власного пакета не знайдено, звірте каталог запуску з розташуванням `go.mod` та module path `example.com/course/practice8a`. Не завантажуйте цей навчальний модуль з інтернету. Якщо обраний `-run` не виконує жодного тесту, перевірте ім’я `Test...`, суфікс `_test.go` та шлях пакета.
