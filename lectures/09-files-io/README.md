# Лекція 9: файли та контрольовані потоки

Задачник отримайте від викладача. Тут лише початкові архіви й інструкції.

- [09-files.zip — F, точні байтові входи](downloads/09-files.zip).
- [09-streams.zip — K, Go-модуль і підміни потоків](downloads/09-streams.zip).
- [SHA256SUMS.txt](downloads/SHA256SUMS.txt).

Потрібен Go 1.24 або новіший (використовується os.Root); перевірено з Go 1.25.1. Підтримуються Windows із PowerShell та Linux/macOS із Bash. Сторонніх бібліотек немає; модуль готовий. Після завантаження мережа не потрібна.

## Перевірка й розпакування

Завантажте обидва ZIP і контрольні суми в один каталог. Перевірте SHA-256 до розпакування.

PowerShell — порівняйте Hash з відповідними рядками SHA256SUMS.txt:
```powershell
Get-FileHash ./09-files.zip -Algorithm SHA256
Get-FileHash ./09-streams.zip -Algorithm SHA256
cat ./SHA256SUMS.txt
```

Bash, Linux:
```bash
sha256sum -c SHA256SUMS.txt
```

Bash, macOS:
```bash
shasum -a 256 -c SHA256SUMS.txt
```

Оберіть новий, ще не наявний каталог task-001. Розпакуйте ZIP так, щоб каталоги 09-files та 09-streams лежали поруч.

PowerShell:
```powershell
Expand-Archive -LiteralPath ./09-files.zip -DestinationPath ./task-001
Expand-Archive -LiteralPath ./09-streams.zip -DestinationPath ./task-001
cd ./task-001/09-streams
go run ./cmd/demo
```

Bash:
```bash
mkdir task-001
unzip 09-files.zip -d task-001
unzip 09-streams.zip -d task-001
cd task-001/09-streams
go run ./cmd/demo
```

Початковий stdout — `READY` з LF, код завершення 0. Файли F доступні за шляхом `../09-files/...`; результати створюйте у власному `out` або `t.TempDir()`. Для незалежної задачі розпакуйте свіжу копію. Не редагуйте байтові входи: відсутність кінцевого LF, CRLF, нульові байти й неправильний UTF-8 навмисні. README набору F містить розміри та SHA-256 кожного входу.

## Модуль і перевірки

README набору K описує готові підміни Reader, Writer і Closer. Вони дозволяють відтворювати помилки без заповнення диска, зміни системних дозволів або доступу до особистих файлів.

**brokenread, brokenwrite та brokenpublish навмисно несправні.** Це початкові програми для регресійних задач 98–100, не зразки правильних реалізацій. Тестів спочатку немає: `[no test files]` не доводить відповідність контракту. Студент пише тести, відтворює помилку й самостійно виправляє її. Готових розв’язків і службових тестів у ZIP немає. Каркас publishcase.go.txt для задачі 93 не входить у звичайну збірку.

PowerShell:
```powershell
go fmt ./...
go test ./... -count=1
go vet ./...
```

Bash:
```bash
go fmt ./...
go test ./... -count=1
go vet ./...
```

Для точних байтових перевірок використовуйте файловий аргумент програми або тести через bytes.Buffer. Текстовий конвеєр PowerShell може змінити кодування чи переноси. У задачнику наведено окремі команди: Bash використовує `<`, а PowerShell запускає cmd для байтового перенаправлення.

Працюйте лише в навчальному каталозі. Cleanup прибирає тільки створений вами temp-файл за точним ім’ям. Не видаляйте стару ціль для обходу помилки Rename. Гарантії атомарності перейменування й права доступу відрізняються між ОС; ці набори не перевіряють стійкість після аварії живлення.
