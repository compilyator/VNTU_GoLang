# Підлекція 8Б: початковий набір для generics

Додаткова практика. Задачник отримайте від викладача; тут розміщено лише початкові файли та інструкцію.

- [08b-workbench.zip — набір K](downloads/08b-workbench.zip).
- [Контрольна сума SHA-256](downloads/SHA256SUMS.txt).

Потрібен Go 1.24 або новіший; перевірено з Go 1.25.1. Підтримуються Windows із PowerShell та Linux/macOS із Bash. Модуль готовий, повторний `go mod init` не потрібний. Після завантаження мережа й сторонні бібліотеки не потрібні.

## Завантаження й перевірка

Збережіть ZIP та SHA256SUMS.txt до одного каталогу. Перед розпакуванням перевірте контрольну суму.

PowerShell — порівняйте Hash із рядком SHA256SUMS.txt:
```powershell
Get-FileHash ./08b-workbench.zip -Algorithm SHA256
cat ./SHA256SUMS.txt
```

Bash у Linux:
```bash
sha256sum -c SHA256SUMS.txt
```

Bash у macOS:
```bash
shasum -a 256 -c SHA256SUMS.txt
```

Для кожної незалежної задачі оберіть новий, ще не наявний каталог, наприклад task-001.

PowerShell:
```powershell
Expand-Archive -LiteralPath ./08b-workbench.zip -DestinationPath ./task-001
cd ./task-001/08b-workbench
go run ./cmd/demo
```

Bash:
```bash
mkdir task-001
unzip 08b-workbench.zip -d task-001
cd task-001/08b-workbench
go run ./cmd/demo
```

Початкове виведення:
```text
READY
```

Код завершення 0. Прочитайте README усередині набору, створіть потрібний пакет і замініть демонстрацію викликами своєї реалізації. Імпорт власного пакета починається з `example.com/course/generics8b/`; це навчальний module path, який не потрібно завантажувати з інтернету.

## Склад набору

`legacy` містить правильні конкретні функції з дублюванням для задач 95–97. **Пакети clone, bounded, minimum, stack, unique навмисно несправні** — це матеріал для регресійних задач 74, 77, 98–100, а не зразки правильних реалізацій. `narrow.go.txt` використовується в окремому досліді 72 й не входить у збірку.

Спочатку тестів немає. `[no test files]` і код 0 означають лише збірку. Напишіть тести за правильним контрактом із задачника, відтворіть дефект, самостійно знайдіть причину, виправте та повторіть перевірку. Готових розв’язків або службових тестів у ZIP немає.

PowerShell:
```powershell
go fmt ./...
go test ./... -count=1
go vet ./...
```

Bash:
```bash
go fmt ./...
go test ./... -count=1
go vet ./...
```

Якщо отримали `[no tests to run]`, перевірте шлях пакета, ім’я Test-функції, суфікс `_test.go` та фільтр `-run`. Навмисно некомпільовані приклади та дослід із panic запускайте окремо й зберігайте як `.go.txt` поза звичайною збіркою. Працюйте лише у власному локальному навчальному каталозі.
