# Приклад `csv-formula`

**Необов’язкове поглиблення**, поза обов’язковим обсягом лабораторної № 4. Передумови: функції, структури, інтерфейси; для форматів — потоки й помилки.

Експорт тексту: звичайний текст не змінюється, =1+1 та @SUM(A1:A2) отримують апостроф. Політика охоплює початкові =, +, -, @, tab і carriage return. Це не універсальний захист усіх табличних програм; CSV-лапки самі собою не блокують формули. Практика: перевірте -2, порожній рядок і початковий пробіл; поясніть зміну семантики чисел.

## Запуск

Go 1.25 зі спільного модуля, без сторонніх залежностей. Із каталогу `examples`, PowerShell або Bash:

```text
go run ./csv-formula
go test ./csv-formula
```

## Практика та LLM

Попросіть онлайн-LLM пояснити очікуваний результат запропонованої вище практики, перевірте його виконанням і виправте неточності. Агенту дозволяйте змінювати лише власну копію прикладу; перегляньте diff і повторіть тести. У журналі зазначте сервіс, модель, якщо відома, дату, мету, істотний запит, використаний результат, власні зміни й спосіб перевірки.

Використовуйте вигадані локальні дані. Демонстрації форматів друкують навчальні помилки; вони не задають контракт кодів завершення повноцінного CLI. CSV-приклади не запускають табличну програму; для дослідів не використовуйте мережеві чи системні формули.
