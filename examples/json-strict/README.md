# JSON із перевіркою контракту

Мета — приймати один невеликий документ запасів і перевіряти його форму та зміст. Потрібні Go 1.25 зі спільного модуля `examples`, структури й вказівники. Сторонніх залежностей немає. Покрокове пояснення — в [інструкції про JSON](../../manuals/go-json/).

Із каталогу `examples`, PowerShell або Bash:

```text
go run ./json-strict
go test -v ./json-strict
```

Результат — форматований JSON із `version: 1`, `name: "Кабель"`, `quantity: 0`. Приклад працює в пам’яті й не змінює файли. Негативні тести відхиляють порушення контракту; перевірка серіалізації та відновлення підтверджує збереження значень.

Навчальні межі: 1024 байти, версія 1, непорожня назва, кількість 0–100. Повторювані ключі та точний регістр імен окремо не перевіряються. Це не універсальний JSON-валідатор.

Для практики перевірте кількості 100 і 101. Попросіть онлайн-LLM запропонувати негативні випадки, обґрунтуйте очікування та перевірте їх тестами. Межі дій агента й склад журналу наведено в розділі «Практика та LLM» інструкції.
