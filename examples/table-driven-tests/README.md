# Приклад `table-driven-tests`: табличні тести

Приклад обчислює середнє арифметичне цілих значень у діапазоні `0..100`. Головна тема — не формула середнього, а організація відтворюваних позитивних, межових і негативних перевірок.

> **Основна інструкція:** цей каталог є виконуваним прикладом до матеріалу [«Основи тестування програм Go»](../../manuals/go-testing-basics/). Для ширшого розуміння вибору вхідних даних також використовуйте інструкцію [«Як перевіряти алгоритм і результати програми»](../../manuals/algorithm-verification/). Там пояснено контракти, ручне визначення очікувань, межові класи, статичні набори й фіксований `seed`.

## Структура

```text
table-driven-tests/
├── README.md
├── main.go
└── main_test.go
```

- `average` перевіряє непорожній набір і діапазон кожного елемента, після чого обчислює результат.
- `main` демонструє один звичайний виклик.
- `TestAverage` містить таблицю сценаріїв і запускає кожний через `t.Run`.

## Запуск програми

Із каталогу `examples`:

```powershell
go run ./table-driven-tests
```

Очікуваний результат:

```text
Середнє: 30.00
```

Набір у `main` статичний: `{10, 20, 30, 40, 50}`. Очікуване середнє легко перевірити вручну: сума `150`, кількість `5`, результат `30`.

## Запуск тестів

```powershell
go test -v ./table-driven-tests
```

Запуск одного підсценарію:

```powershell
go test -v -run 'TestAverage/lower_boundary' ./table-driven-tests
```

У PowerShell і Bash одинарні лапки захищають регулярний вираз від обробки оболонкою.

## Як побудована таблиця

Кожен рядок містить:

- `name` — змістовну назву сценарію;
- `values` — статичний вхід;
- `want` — очікуваний результат;
- `wantError` — чи має функція відхилити дані.

Поточні сценарії перевіряють звичайний набір, обидві межі діапазону, порожній набір і значення за нижньою та верхньою межами.

## Чому дані статичні

Точний вхід видно в коді, очікування можна порахувати незалежно, а падіння повторюється на іншому комп’ютері. Генератор випадкових даних тут не дає навчальної переваги й лише ускладнює діагностику.

## Експерименти

1. Додайте набір із двох різних значень.
2. Додайте допустимі повтори.
3. Створіть сценарій, у якому неправильний елемент розташований не першим.
4. Навмисно змініть `>` на `>=`, запустіть тести й визначте, які межові сценарії виявили дефект; потім поверніть правильну умову.
5. Поясніть, чому очікуване середнє не слід обчислювати викликом `average`.

## Типові помилки

- однакові назви підсценаріїв;
- лише один успішний випадок;
- випадковий набір без фіксованого `seed`;
- обчислення `want` тестованою функцією;
- перевірка лише наявності помилки без перевірки успішного результату;
- використання надто великого набору, який важко перевірити вручну.
