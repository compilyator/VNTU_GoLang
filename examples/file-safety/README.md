# Файлові операції без перезапису

Мета — перевірити межу читання й зберегти оригінальний файл після невдалої спроби заміни. Потрібні Go 1.25 зі спільного модуля `examples`, знання функцій і помилок; сторонніх залежностей немає. Пояснення — в [інструкції про файли](../../manuals/go-files-io/).

Із каталогу `examples`, PowerShell або Bash:

```text
go run ./file-safety
go test -v ./file-safety
```

Очікувано:

```text
Байтів: 8; прийнято: true
Байтів: 9; прийнято: false
Перезапис відхилено
```

Демонстрація створює власний тимчасовий каталог і прибирає його. Тест перевіряє вміст після відхиленого запису та помилку відсутнього каталогу. Перевірка не моделює вимкнення живлення або зловмисну заміну каталогів.

Для практики змініть межу й перевірте значення по обидва боки. Попросіть онлайн-LLM пояснити різницю між `O_EXCL` і попереднім `Stat`; перевірте відповідь за інструкцією й тестом. Правила меж роботи агента та журналу — у розділі «Практика та LLM» інструкції.
