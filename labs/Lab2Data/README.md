# Генератори даних для лабораторної роботи № 2

Модуль містить 30 незалежних пакетів із навчальними генераторами. Студент підключає лише пакет свого варіанта. Генератори імітують форму даних майбутнього зовнішнього API, але не виконують аналіз замість студента.

Канонічний шлях модуля: `github.com/compilyator/VNTU_GoLang/labs/Lab2Data`.

Дані є синтетичними. Псевдовипадковий генератор призначений для навчальних наборів, а не для паролів, токенів або інших безпекових задач.

## Контракт

Кожен пакет експортує дві функції:

```go
Generate(count int, subject string) ([]T, error)
GenerateWithSeed(count int, subject string, seed int64) ([]T, error)
```

де `T` — `int` або `float64` відповідно до предметного показника, а `subject` — непорожній предметний параметр варіанта: місто, країна, валютна пара, тег, тикер тощо.

- `Generate` створює новий псевдовипадковий набір;
- `GenerateWithSeed` дає однаковий набір для однакових `count`, `subject` і `seed`;
- зовнішні пробіли вилучаються, а регістр `subject` не впливає на хеш;
- порожній або складений лише з пробілів `subject` повертає помилку;
- нормалізований `subject` хешується через FNV-1a, а хеш змішується із seed;
- дозволена кількість — від 5 до 100;
- кожен набір містить значення з різних категорій і щонайменше один повтор;
- генератор не обчислює суму, мінімум, максимум, середнє, категорії чи частоти.

## Приклад

```go
values, err := temperature.Generate(20, "Вінниця")
if err != nil {
	fmt.Println("Не вдалося створити дані:", err)
	return
}
```

Для відтворюваної перевірки:

```go
values, err := temperature.GenerateWithSeed(20, "Вінниця", 42)
```

Зміна міста за незмінного seed змінює набір. Це не модель реальної погоди, а детерміноване розділення навчальних даних.
